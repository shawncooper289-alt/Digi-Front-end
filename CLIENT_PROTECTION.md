# Ava Skye Frontend Notes

This repository contains only the Ava Skye frontend deployed on Vercel.

Backend systems, Ava OS, knowledge-base services, and Base44 integrations are separate projects and should not be represented as bundled frontend functionality here.

## Frontend responsibilities

- Render the public Ava Skye landing experience
- Keep browser-facing copy focused on Ava Skye
- Avoid exposing backend API keys or implementation details in client-side code
- Deploy through the Vercel Next.js project preset
