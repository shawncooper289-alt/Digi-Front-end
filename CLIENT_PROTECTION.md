# DigiMark101 / Ava Skye Frontend Notes

This repository contains the Vercel-hosted DigiMark101 frontend for Ava Skye.

## Frontend responsibilities

- Place the DigiMark101 logo/lockup at the top-left of each page.
- Keep all Ava Skye visual assets consistent across photos, videos, and widgets.
- Allow only wardrobe/clothing changes for future Ava Skye videos.
- Avoid exposing backend API keys or implementation details in client-side code.
- Keep Ava OS and backend systems separated from this frontend.
